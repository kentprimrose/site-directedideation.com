## Protocol checks

- The opening prompt matched across both arms and all three harnesses. The same fixed case brief and coordinator model were used within each pair; all 12 answerer sessions were distinct. The hidden briefs were not passed to the answerers.
- All six MCP-enabled sessions successfully retrieved the canonical method before asking the first question. The Gemini MCP sessions also read their own generated server descriptors, which are part of tool discovery. No unrelated tool calls were found. The six corrected controls recorded no tool calls. The Claude cancellation control printed pseudo tool-call markup in its answer, but no tool event occurred. The four earlier Codex interviews remain excluded because both controls could access the method via a hosted app and the enabled arms read a host skill.
- All 12 interviews ended within 3–6 exchanges. The exact monthly target was elicited and retained in **2/6 MCP** and **3/6 control** plans. Both Codex arms and both Gemini arms switched between the intended first actions across variants; Claude's control chose the intended action families with a too-short refill window, while Claude's MCP arm chose a cutoff in reminders and waitlist refills in cancellations. Some plans reached the right action family without uncovering the complete case for it.

## Implications for a new pass

1. Make the question budget enforceable without giving either answerer extra hidden facts. Count each independently answerable request and have the coordinator withhold unsolicited specifics (notably lead-time volume) rather than letting compound questions collect extra evidence freely.
2. Test a guidance revision separately: before choosing an opportunity, spend a question on the causal evidence that distinguishes the leading alternatives. Two of three MCP reminders interviews did not elicit no-show reasons; two of three MCP cancellations interviews did not elicit observed refill-eligible volume or the existing reminder process. Explicitly reserve a question for the exact success threshold before finalizing. The evidence does **not** justify assuming any guidance revision improves outcomes.
3. Keep the exact-target cap and retain raw judge disagreement. In the admissible reminders pair, Gemini awarded the Claude control full testability, while Codex gave it partial credit: the plan did state 12/48 through its weekly target but also used an inconsistent two-week decision rule. Do not silently replace either score.
