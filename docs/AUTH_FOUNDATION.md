# Authentication foundation (not deployed)

This internal library is not wired to HTTP or MCP and does not protect either. Apply `site_directedideation_com.auth.schema.upgrade(engine)` explicitly to an empty database; it is the initial schema, not a versioned migration framework. Use a SQLAlchemy MySQL/MariaDB engine with PyMySQL and transactional InnoDB tables. SQLite is used for offline tests only; it ignores row-level `FOR UPDATE` locks and does not establish production concurrency guarantees. Token issuance requires the caller to hold the account row's write lock (or have inserted the account in the same transaction). No credentials or delivery implementation are supplied.

Email is printable ASCII, trimmed and case-folded to lowercase; this is a deliberate pilot identity policy, not full RFC internationalized email support. Passwords require 12–1024 characters and use Argon2id. Verification and password tokens are random, stored only as SHA-256 digests, expire after 30 minutes, are purpose-bound and atomically consumed. Verification delivers a separate password-setting token; accounts cannot authenticate until both steps complete. Delivery is injected, occurs after commit, and failures are suppressed to avoid account enumeration; users can request a replacement. Delivery systems must protect secrets and avoid logging them. Registration and reset requests return the same value regardless of account status; verification, password setting and authentication return success or failure. Timing and delivery side channels are not eliminated.

Before exposing any endpoint: add effective distributed rate limiting and abuse controls, generic response and timing review, secure token transport without URL secrets, delivery failure monitoring without sensitive data, schema versioning and tested migrations, MySQL concurrency/integration tests, operational secret handling and independent security review. Existing tokens are not sessions or MCP credentials. Team authorization, credential integration, live email, deployment, account deletion, session revocation and US eligibility are outside this slice. No pilot readiness is implied.
